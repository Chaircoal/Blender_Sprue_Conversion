# Blender_Sprue_Conversion
Takes 3D blender model for slicing, generates sprue and attaches gates. Conversion tool for model to sprue.

"sprue_converter_addon" folder should be compressed to zip
- In blender, EDIT -> Preferences -> Add-ons ->(Top right dropdown -> Install From Disk) -> 'select sprue_tool.zip'
- Check ON if not already (Checkbox should be marked)
- Hotkey 'N' to open sidebar with 'Sprue Tool' now available
